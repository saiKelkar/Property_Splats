# Property-Splats

Gaussian splatting pipelines for real estate: turning phone videos of rooms, interiors and buildings into interactive 3D tours.

Built with COLMAP + Nerfstudio (splatfacto) on Google Colab.

## Notebooks
- `01_pipeline_test_mipnerf360_room.ipynb`: pipeline test on the Mip-NeRF 360 "room" dataset (research dataset, used for learning only)
